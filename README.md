# ✅ To-Do List App

A simple and responsive **To-Do List application** built using **HTML, CSS, and JavaScript**.

The application helps users organize their daily tasks by allowing them to create, complete, edit, and delete tasks.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 View task list
- 🔍 Filter tasks
- 📊 Track completed and pending tasks
- 💾 Store tasks using browser Local Storage
- 📱 Responsive design
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
